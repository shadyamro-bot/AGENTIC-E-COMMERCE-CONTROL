# AEC Interactive Demo v1.1

هذه الحزمة جاهزة للرفع مباشرة على Netlify.

## التحديثات
- أوامر إنشاء المنتج بالعربية والإنجليزية.
- استخراج SKU والألوان والمقاسات والسعر وبلد المنشأ والوزن وFBA/MFN.
- إنشاء Parent وجميع Child variations.
- شريط مرئي لمراحل Command → Draft → Validate → Approve → Publish.
- Validation Preview تجريبي مع ملاحظات Color Map.
- زر شرح تفاعلي داخل كل صفحة.
- تصدير نسخة احتياطية من بيانات التجربة بصيغة JSON.
- زر Reset لإعادة بيانات الـDemo للحالة الأصلية.
- أمثلة WhatsApp بالعربية والإنجليزية.

## الرفع
ارفع ملف ZIP إلى Netlify Deploys، أو فك الضغط وارفع محتويات المجلد. يجب أن يكون index.html في الجذر.

## الأمان
هذه نسخة Demo فقط. لا تضع بها Amazon Client Secret أو Refresh Token أو WhatsApp access token.
