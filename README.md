# AGENTIC E-COMMERCE CONTROL — Railway Unified v1.2

Production-oriented Node.js + Express + PostgreSQL application for Amazon Egypt operations.

## Features

- Product command parsing and Parent/Child generation
- PostgreSQL products, variants, approvals, users and audit history
- Role-aware product editing and validation
- Amazon file intake for XLSX, XLSM, XLS and CSV
- File fingerprinting and row-level issue summaries
- Variant image URL management
- Persistent notifications
- Safe WhatsApp/n8n simulation layer
- Amazon connection readiness wizard
- Simulation Mode and Emergency Lock

## Start

```bash
npm install
npm start
```

Required: `DATABASE_URL`.
